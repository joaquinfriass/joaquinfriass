## 🚀 Proyectos

### 🎭 1. Automation Exercise · Playwright + TypeScript
Suite E2E sobre un e-commerce, con **Page Object Model**, **fixtures propias** y **generación dinámica de datos** (factories) para evitar usuarios duplicados. Cubre flujos de registro y carrito, con capturas automáticas y reporte HTML.
🔗 [Ver proyecto](https://github.com/joaquinfriass/AutomationExercisePlaywright)

### 🧪 2. Automation Sandbox · Playwright + GitHub Actions
Pruebas sobre componentes de UI (nuevas pestañas, elementos dinámicos, checkboxes, radios, dropdowns nativos y custom) con POM y un **pipeline de CI en GitHub Actions** que corre en cada push y pull request.
🔗 [Ver proyecto](https://github.com/joaquinfriass/AutomationSandBox-Playwright)

### 🔌 3. API Testing · Java + REST Assured + Allure
14 casos de prueba sobre la API de Automation Exercise: CRUD completo de cuentas, login (válido, inválido y sin parámetros) y validación de métodos no permitidos (405), con reportes **Allure** por severidad.
🔗 [Ver proyecto](https://github.com/joaquinfriass/RestAssured_Allure_AEAPI)

### 🥒 4. UI · Java + Selenium + Cucumber (BDD)
Automatización E2E de registro, login y gestión de cuentas con escenarios en Gherkin, POM y reportes Allure.
🔗 [Ver proyecto](https://github.com/joaquinfriass/AutomationExerceise-Selenium-Framework)
